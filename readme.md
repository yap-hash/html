# 🌿 Paradise Nursery - E-commerce de Plantas de Interior

## 📋 Descripción del Proyecto
Paradise Nursery es una aplicación de comercio electrónico desarrollada con React y Redux para la venta de plantas de interior. Los usuarios pueden explorar diferentes categorías de plantas, agregar productos al carrito y gestionar sus compras.

## 🚀 Tecnologías Utilizadas
- React 18
- Redux Toolkit
- React Router DOM
- CSS3

## 📦 Características Principales
- ✅ Listado de plantas agrupadas por categorías
- ✅ Carrito de compras con persistencia de estado
- ✅ Gestión de cantidades por producto
- ✅ Navegación entre páginas
- ✅ Indicador dinámico de artículos en el carrito
